## Введение
Меня заинтересовал вопрос создания своей хеш-таблицы и последующего ускорения её работы. 

## Что такое Хеш-таблица
Это особый тип контейнера для данных, где храняться сами значения или пары (ключ-значение).

<img src="./readme_src/table_scheme1.png" width="800"/>

Есть два основных способа представления бакетов с данными: бакет = отдельное значение, бакет = список из нескольких значений, для хеш-таблиц реализованных методом открытой адресации и методом цепочек соответственно. 

Когда слово для поиска поступает на вход, оно обрабатывается хеш-функцией для получения ключа(номера бакет)а, соответствующего данному слову. 

В связи с неполной рандомизированностью выходных значений хеш-функции от разных входных значений и/или малыми размерами массива для хранения данных, возникает явление коллизии. Это явление, при котором нескольким входным значениям соответсвует один ноиер бакета.
